# Avrora Tech — Sitio Web Oficial

Sitio web corporativo de **Avrora Tech**: ingeniería de software, inteligencia artificial, automatización y soluciones electrónicas / hardware.

## 🌐 Tecnologías
- HTML5 semántico
- CSS3 Vanilla (Diseño responsivo, animaciones modernas, soporte para modo oscuro / temas y alto contraste)
- JavaScript Vanilla
- SEO y OpenGraph optimizados
- PWA / Web Manifest configurado

## 📁 Estructura del Proyecto
```
├── assets/          # Imágenes, logos e iconos
├── css/             # Hojas de estilo (style.css)
├── js/              # Scripts de interactividad y animaciones (script.js)
├── index.html       # Página principal
├── servicios.html   # Catálogo detallado de servicios
├── 404.html         # Página de error 404 personalizada
├── sitemap.xml      # Mapa del sitio para indexación SEO
└── site.webmanifest # Manifiesto para instalación PWA
```
